# Pins

Collections of passages, tables, figures and code you've pinned, each with a note, for a piece of
work: a review, a design, a question for a meeting.

- **Pin to** in the bottom bar chooses the collection new pins go to. Pin from a search result, from
  a page, or from a code symbol (**Pin** in the code inspector).
- A pin keeps where it came from: document, clause, page, the document's distribution statement;
  for code, the file and line. **View page** opens it.
- **Note** records why it matters or what's open.
- **Export with citations** writes the collection to **Word** or **Markdown**, every pin with its
  citation and the document's marking.
- **Cite when copying** (bottom bar) makes every **Copy** button add the citation to what's copied.

New collections are made at the top of the view; **Rename** and **Delete** are beside the name.
